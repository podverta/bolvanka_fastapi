# Проект для создания скриншотов веб-страниц

Этот проект позволяет создавать скриншоты веб-страниц по запросу с помощью FastAPI, Celery и Pyppeteer. Скриншоты сохраняются на сервере и доступны для скачивания. Проект использует PostgreSQL для хранения данных, Redis для очередей задач, и Docker Compose для упрощения запуска.

## Стек технологий

- **FastAPI**: API-сервер.
- **Celery**: Система обработки фоновых задач.
- **Redis**: Брокер очередей задач.
- **Pyppeteer**: Инструмент для работы с браузером и создания скриншотов.
- **PostgreSQL**: База данных.
- **Docker Compose**: Оркестрация всех сервисов.

## Установка и запуск

### 1. Клонирование репозитория
#### Внимание, для сборки необходим docker-compose, если нет, установи.

```bash
git clone <URL репозитория>
cd <папка проекта>
```
### 2. Запуск проекта

```bash
docker-compose up --build
```

### 3. Как юзать? Перейди на доку:

```http request
http://0.0.0.0:8888/docs
```
